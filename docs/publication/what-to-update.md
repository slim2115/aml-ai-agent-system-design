## Как отправить

Используйте [самодостаточную инструкцию с командами](../publication.md). Она создаёт новый чистый клон в отдельном родительском каталоге, проверяет текущую базу main, копирует полную поставку, сверяет хэши и состав diff. Старый checkout и уже использованный клон сохраняются.

Сначала выполняется commit/push проверок QA, затем commit/push документации. Для каждого коммита инструкция содержит понятные сообщения с двумя параметрами -m и проверяет точный набор staged-файлов. Commit и push выполняет владелец. После каждого push проверяется GitHub Actions для нового SHA.

Если main изменится до вашей отправки, базовый guard остановит перенос. Сначала нужно повторить сравнение; менять базовый SHA без сверки нельзя.
