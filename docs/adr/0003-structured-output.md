# ADR-0003: Structured Output (JSON Schema) вместо свободного текста

## Статус
Accepted

## Дата
Июль 2026 г.

## Контекст
Черновик отчёта потребляется несколькими способами: валидируется автоматически, отображается
в UI с подсветкой доказательств (BR-06), экспортируется в Case Management (SR-22).
Свободный текст LLM не позволяет гарантировать структуру, автоматически проверить полноту
разделов и связать утверждения с первоисточниками (`evidence_ref`, `source_ref`).

## Решение
Ответ агента строго соответствует **JSON Schema (draft-07)** — артефакту `AMLInvestigationDraft`
(SRS, раздел 5). Схема фиксирует:
* обязательные разделы: `found_facts`, `suspicious_patterns`, `applicable_rules`;
* структуру доказательства `evidence_ref` (`tx_id` + `field`) для grounding (SR-14);
* ссылки на нормативные пункты `source_ref` для трассировки (SR-11);
* условные требования: при `status=refusal` обязателен `refusal_reason`, при `status=draft` —
  разделы `found_facts` и `applicable_rules`.

Генерация сопровождается валидацией схемы перед передачей оператору (SR-08); при несоответствии —
повторная генерация или явный отказ.

## Рассматриваемые альтернативы
* **Свободный текст (free-form):** отвергнуто. Невозможны автоматическая валидация,
  измеримый Schema Match и машиночитаемая трассировка; высокий риск «воды» и галлюцинаций.
* **Только Markdown:** отвергнуто как основной формат. Markdown удобен для чтения оператором,
  но не обеспечивает строгой валидации и связей `evidence_ref`/`source_ref`. Используется как
  производное представление (рендер из JSON) для финального отчёта и reasoning chain.

## Последствия
* **Положительные:** измеримая метрика Schema Match = 100% (NFR-01); надёжная интеграция
  с UI и Case Management; формализованная трассировка (BR-04, BR-05).
* **Отрицательные:** ограничение выразительности модели жёсткой схемой; необходимость
  retry-логики при нарушении схемы.
* **Риски:** усложнение промпта для удержания формата; митигируется версионируемой
  prompt-спецификацией (SRS раздел 4) и регрессионными тестами.
