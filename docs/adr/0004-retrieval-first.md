# ADR-0004: Retrieval-first (RAG) как основа генерации правил

## Статус
Accepted

## Дата
Июль 2026 г.

## Контекст
Критическое требование комплаенса — 100% прослеживаемость каждого вывода до пункта нормативной
базы (BR-04) и запрет генерации несуществующих правил (BRULE-02). Генерация правил из параметрических
знаний модели недопустима: модель галлюцинирует статьи и пункты (RISK-AI-01), что ведёт к провалу
внешнего аудита.

## Решение
Применить **Retrieval-first (RAG)** подход:
* применимые правила извлекаются семантическим поиском только из утверждённой базы знаний
  комплаенса (SR-07);
* каждый вывод сопровождается ссылкой `source_ref` на конкретный пункт регламента (SR-11);
* ссылка сверяется с существующими записями базы знаний; несуществующая ссылка отклоняется (SR-12);
* база знаний хранится в виде чанков по статьям/пунктам с метаданными
  (`rule_id`, `regulation_ref`, `category`) — формат зафиксирован в Data Model (раздел 4).

## Рассматриваемые альтернативы
* **Fine-tuning модели на регуляторной базе:** отвергнуто. Дорого, сложно обновлять при изменении
  регламентов, не даёт гарантированной трассировки до пункта; модель по-прежнему может галлюцинировать.
* **Правила целиком в контексте промпта (без retrieval):** отвергнуто. Не масштабируется на базу
  >500 страниц (pain point As-Is), превышает контекстное окно, не обеспечивает точного извлечения.
* **Гибридный (RAG + fine-tuning):** допускается как направление развития для Production,
  но для PoC достаточно RAG при целевом Faithfulness ≥ 90%.

## Последствия
* **Положительные:** измеримые Traceability Ratio = 100% (NFR-04) и RAG Precision/Recall = 100%
  (NFR-12); актуальность правил обеспечивается обновлением базы знаний без переобучения модели;
  юридическая чистота отчётов.
* **Отрицательные:** качество вывода зависит от качества чанкинга и embedding-модели;
  необходимость поддержки векторной БД.
* **Риски:** ошибка retrieval (не найден нужный пункт) ведёт к отказу или неполному отчёту;
  митигируется метрикой RAG Precision/Recall и политикой явного отказа (BRULE-03).
