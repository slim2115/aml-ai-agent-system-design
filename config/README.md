# Конфигурация независимой копии

Текущая настройка процесса выполняется `scripts/rebuild/Enter-LocalEnvironment.ps1`. Абсолютные пути рассчитываются от расположения нового проекта. Пример `.env.example` не содержит секретов; настоящий `.env` не копируется и не создаётся.

Подготовлены отдельные каталоги runtime и offline-cache. Файлы моделей туда пока не переносились; отключённый доступ к Hugging Face предотвращает неявное скачивание при будущем ошибочном запуске. Это настройка рабочего процесса, а не реализованный firewall или полная защита периметра приложения.

Параметры PostgreSQL и API будут добавлены после определения контрактов. Унаследованные `DATABASE_URL` и `SQLALCHEMY_DATABASE_URI` очищаются только в текущем процессе. Учебные write-права и read-only-доступ агента будут разделены.

В исходном `src/config.py` остаются исторические defaults, а embedding-модель задана в retrieval константой. Исправление этих контрактов и зависимостей относится к следующим блокам. Установленный здесь порог retrieval 1.0 сохраняет целевое требование, но не исправляет сам оценщик.
