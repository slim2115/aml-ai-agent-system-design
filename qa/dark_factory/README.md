# Dark-factory QA: паспорт исходных свидетельств

Эта отдельная утилита фиксирует выбранные исторические результаты и SHA256 входных файлов. Она не вызывает модель, не принимает решение оператора и не обновляет старые свидетельства. Полная инвентаризация — `capture_status=PASS`, но это не приёмка качества. Исторический `FAIL` Judge сохраняется; человеческая калибровка и приёмка всегда `INCOMPLETE`.

Из корня подготовленного rebuild:

```powershell
.\.venv\Scripts\python.exe -I -B qa/dark_factory/baseline.py --output var/qa/dark-factory/baseline-01.json
```

Имя должно быть новым: запись выполняется в новый файл, существующий результат не перезаписывается. Отсутствующий или некорректный вход даёт `capture_status=INCOMPLETE` и код выхода 2. Утилита сохраняет только имена разрешённых входов, хеши и небольшие заранее определённые агрегаты; сырые промпты, ответы, персональные данные и локальные секреты не сохраняются. Созданный в прошлом результат не является свидетельством нового запуска или независимой проверкой полной цепочки исходных артефактов.

Проверка только этого компонента:

```powershell
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider tests/dark_factory/test_baseline.py
```
