# Учебный benchmark поиска v1

Разметка зафиксирована до запуска модели: 13 проверок, из них пять основных положительных запросов, три алиаса, три варианта даты редакции, один запрос без прямого соответствия и один случай без действующих редакций. Это пять текстовых тем на общем корпусе, а не 13 независимых наблюдений. Повторы и алиасы не увеличивают знаменатель основного среднего. Набор открыт, не является внешней отложенной выборкой и не подтверждён AML-экспертом.

Копии `corpora/base.json` и `corpora/editions.json` побайтно соответствуют замороженным S01/S04 из `aml-v1`. Юридическая корректность синтетических формулировок не установлена. Релевантность означает прямое соответствие текста теме запроса. Применимость правила определяется отдельной учебной политикой; например, `reporting` присутствует в поисковом наборе, но не в отображении alert → разрешённые правила.

Перед измерением закреплены `k=[1,3]`. Сохраняется полная непосредственно полученная выдача: позиции, расстояния, полные цитаты и границы фрагментов. Метрики precision@k, recall@k и MRR диагностические, без придуманного порога приёмки. Они не переименовываются в M-07. Для единственного релевантного фрагмента максимальное precision@3 равно 1/3. Основное среднее рассчитывается только для R01–R05; остальные случаи показываются отдельно. Для отсутствующей релевантности recall и MRR не определены и не входят в среднее. Не следует подменять отсутствие измерения значением 1.

`velocity` не имеет прямого соответствия в корпусе. Поиск при этом вправе вернуть ближайшие фрагменты: в нём нет порога отказа. R13 проверяет другой случай — все редакции ещё недействительны, поэтому выдача пуста. R09–R11 фиксируют исключительную верхнюю границу старой редакции и преобразование времени в UTC по учебной конвенции системы.

Ожидаемые цитаты вычислены из полных текстов без вызова модели и без копирования результата поиска. Для каждого короткого текста задан один фрагмент `[0,len(text))`; настоящий tokenizer должен подтвердить это допущение. Идентификатор — `chunk-` плюс SHA-256 канонического UTF-8 JSON `{rule_id,version,source_ref,char_start,char_end,text_sha256}`. Ключи сортируются, разделители — `,` и `:`, символы Unicode не экранируются. SHA текста считается по точным UTF-8 байтам. Активный набор размечен до ранжирования.

`build_dataset.py` — одноразовый авторский инструмент на стандартной библиотеке; он отказывается перезаписывать созданный набор и не импортирует приложение, модель или tokenizer. `manifest.json` запечатывает код автора, описание, каталог и копии корпусов. Загрузчик `qa/retrieval_dataset.py` проверяет закреплённый хеш манифеста, файлы, происхождение, даты и разметку; запуск benchmark не перестраивает эталоны. Изменение формулировок или ожиданий требует новой версии с объяснением, а не обновления золотого ответа по результату неуспешного прогона.
