# Интерфейс аналитика QA

Этап 8 показывает сохранённые свидетельства этапов 3–7 в отдельном локальном Streamlit-приложении. Требования и причины выбора проверок читаются из плана общего запуска. Установка и практические команды полностью приведены в [разделе 10.13 руководства](../../docs/operator/service-and-lab.md#qa-analyst).

```powershell
.\.venv-ci\Scripts\python.exe -I -B -m streamlit run qa/analyst/app.py --server.address 127.0.0.1 --server.port 8502 --server.headless true --browser.gatherUsageStats false
```

Откройте http://127.0.0.1:8502. Для просмотра не нужны Ollama, MiniLM, PostgreSQL, API или Kafka. Завершите процесс через Ctrl+C. UI оператора на 8501 запускается отдельно.

## Данные и доверие

Reader перечисляет только непосредственные каталоги `var/qa/execution`, `var/qa/evaluator-qualification`, `var/qa/environments`, `var/qa/stability`, `var/qa/autonomy`. Имена ограничены 64 символами; сортировка обратная лексикографическая, не по времени исполнения. Незавершённый каталог без `result.json` имеет INCOMPLETE; наличие живого процесса не проверяется.

`result.json` — локальное записанное утверждение. Экран выбирает разрешённые поля, а не исполняет содержимое `report.md`, команды, ссылки или HTML. Raw-ответы модели, prompts, секреты и тела журналов не выводятся. В плане видны требования, профили и причины выбора; в autonomy — контроли, первая и окончательная оценки, попытки, бюджет и хронология. В stability остаются видны пропуски и неизвестный расход.

Кнопка проверки сверяет хэши всех файлов из `evidence.json` и сравнивает `source-before.json` с новым снимком исходников. `MATCH` означает совпадение байтов на момент проверки, `DIFFERENT` — другую текущую версию. `ERROR`/`UNAVAILABLE` запрещают трактовать проверку как подтверждение. После следующего действия результат проверки сбрасывается в NOT_CHECKED; сохранённый исходный verdict не переписывается.

Хэши не являются независимой подписью; согласованная подмена всех локальных файлов владельцем не обнаруживается как подделка. Проверка не повторяет семантическую оценку, не аттестует ОС, установленную сегодня модель или окружение запуска. Записанный FAIL сохраняется при ошибке чтения других свидетельств. Продуктовая приёмка всегда INCOMPLETE, допуск кандидата NOT_EVALUATED.

## Ограничения чтения

- До 500 записей каталога, 2000 закреплённых файлов, 32 МиБ на файл и 256 МиБ прочитанных байтов на один просмотр; превышение даёт ошибку.
- Строгий JSON отвергает повтор ключей, NaN/Infinity и некорректные типы выбранных полей. Таблицы ограничены по количеству строк.
- Не разрешены symlink, junction, hardlink, абсолютные пути, `..`, альтернативные потоки Windows и произвольные внешние каталоги.
- Внешние pins разрешены только для дочернего результата требований данного execution, принадлежащего запуску workspace environment-models и ограниченных исторических LLM-источников stability. Внешние данные только хэшируются; их содержимое не отображается.
- При чтении проверяются метаданные файла; после длительной проверки повторно читаются result и manifest. Это проверка в момент чтения, не блокировка файлов от конкурентного редактирования.

Интерфейс не запускает тесты, модели, Git, SQL или деплой, не принимает решение об AML-кейсе и не изменяет старые свидетельства. Кэш или обычные служебные данные Streamlit не являются результатами QA.

## Проверки интерфейса

Unit/AppTest проверяют пути и размеры, повреждения, исходный FAIL после исправления, отсутствие утечки raw-payload, неизвестный расход и сброс устаревшей проверки при rerun. Они включены в общую регрессию.

`qa/tools/check_analyst_browser.py` отдельно проверяет настоящим Chromium уже запущенный UI на 8502 (18502 зарезервирован для проверки). Требуются установленные фиксированные browser tools. Аргументы `--kind`, `--run-id` выбирают существующий читаемый запуск; `--output-dir` — новый каталог `var/qa/analyst-browser/<имя>`. Проверяются выбор запуска, сохранение verdict, явная проверка, незавершённая приёмка и сброс проверки после обновления. Сохраняются screenshot и JSON с хэшем исходников; внешние HTTP/WebSocket-адреса страницы блокируются. Это не системный сетевой экран и не профиль браузерной проверки AML-оператора.

Учебные расследования составляют следующий этап 9. Независимая человеческая калибровка и удалённый CI новой публикации остаются отдельными проверками.
