# Сравнение baseline и candidate

`comparison.compare(spec, baseline, candidate)` — локальный стандартный Python-модуль, сравнивающий **уже проверенные вызывающим кодом** синтетические наблюдения. Он не вызывает модель, не проверяет происхождение входов и не является независимым оценщиком или подтверждением продуктовой приёмки. Открытые локальные сценарии не считаются закрытым holdout.

`spec` содержит `catalog_sha256` и `cases`: записи `case_id`, `family`, `case_sha256`. Каждый `run` содержит `run_id`, `catalog_sha256`, `code_sha256`, `model_sha256`, `prompt_sha256`, `attempts`; попытка содержит поля сценария плюс `attempt` (целое от 1), `status` (`PASS`, `FAIL`, `ERROR`, `TIMEOUT`, `INCOMPLETE`). Имена — безопасные синтетические идентификаторы, хэши — 64 строчные шестнадцатеричные цифры. Дополнительные поля, в том числе сырые prompt/ответ/секреты, отвергаются.

Оба запуска должны ссылаться на идентичные каталог и случаи. Код, модель и prompt могут отличаться, но идентичности выводятся отдельно. Отсутствующая или незавершённая **первая** попытка даёт `INCOMPLETE`, успех повтора не маскирует первый `FAIL`/`TIMEOUT`. `MEASURED` означает лишь наличие пар, а не качество AI или общую приёмку. Число семейств описательно и не означает статистически независимые случаи.

Запуск из корня подготовленного окружения:

```powershell
.\.venv\Scripts\python.exe -I -B -m pytest -c pyproject.toml tests/dark_compare -q -p no:cacheprovider
```
