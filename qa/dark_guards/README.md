# Проверка целостности оценщика

`integrity.capture` вычисляет размеры и SHA256 явно перечисленных файлов оценщика. `commitment` даёт хэш инвентаря; `verify` обнаруживает изменение или исчезновение указанных файлов и отклоняет переписанный инвентарь, если ему передан прежний отпечаток. В `tests/dark_guards` есть контролируемые примеры удаления проверки и подмены эталона во временной папке.

Это учебная диагностика заданного набора файлов. Она не проверяет файлы за его пределами, не предотвращает одновременное изменение кода, инвентаря и отпечатка, не является криптографической подписью и не создаёт секретный holdout. Настоящий контроль требует независимо защищать исходный отпечаток, границы доступа и исполнителя; в общей папке такая изоляция не заявлена. Тесты не изменяют настоящие файлы оценщика.

Запуск из корня проекта:

```powershell
.\.venv\Scripts\python.exe -I -B -m pytest -c pyproject.toml tests/dark_guards -q -p no:cacheprovider
```
