# Учебный SQL/API

Откройте в Проводнике **AML SQL API - Start.lnk**: запустятся PostgreSQL/API и DBeaver.
Для завершения выберите Commit/Rollback в DBeaver, отключите подключения и откройте **AML SQL API - Stop.lnk**.

[Инструкция DBeaver](../../docs/operator/dbeaver-quickstart.md) · [Стартовый SQL](../sql/dbeaver-start.sql) · [Swagger](http://127.0.0.1:8765/docs).

Ярлыки создаёт `scripts/lab/Setup-DBeaver.ps1`; они привязаны к папке этого локального стенда. Kafka, её обработчики и модели запускаются отдельно.
