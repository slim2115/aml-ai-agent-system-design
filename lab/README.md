# Локальный стенд SQL и API

PostgreSQL 17.11 и FastAPI работают внутри отдельного проекта `.`. Стенд использует синтетические данные прототипа. Для SQL и API-упражнений модели и Ollama не требуются.

## Запуск и остановка

В PowerShell 7 (`pwsh`) из каталога новой копии:

```powershell
# Терминал открыт в корне вашей копии проекта.
.\scripts\lab\Start-Lab.ps1
```

Откройте [Swagger UI](http://127.0.0.1:8765/docs). Команда запускает два фоновых процесса на loopback, без установки службы Windows. Повторный запуск сохраняет данные. После перезагрузки компьютера запустите её снова.

```powershell
.\scripts\lab\Stop-Lab.ps1
```

Остановка закрывает API и его workflow, затем собственный кластер PostgreSQL. Данные сохраняются. Команды не запускают и не останавливают общий Ollama.

Первичная подготовка уже выполнена. Для восстановления установки в этом же каталоге предусмотрены последовательные команды:

```powershell
.\scripts\lab\Install-LabDependencies.ps1
.\scripts\lab\Initialize-Lab.ps1
.\scripts\lab\Start-Lab.ps1
```

Установка требует доступа к PyPI, EDB и npm; обычный запуск работает с локальными файлами. PostgreSQL ZIP занимает около 380 МБ, распакованный сервер и кластер — дополнительное место. ZIP выбран для отдельного локального окружения; этот вариант предусмотрен [официальной страницей PostgreSQL для Windows](https://www.postgresql.org/download/windows/). Хэш архива фиксируется после загрузки; независимый опубликованный хэш поставщика не получен. Python wheels сверены с SHA-256 PyPI, Swagger — с integrity npm. JavaScript/CSS Swagger размещены локально по [схеме FastAPI](https://fastapi.tiangolo.com/how-to/custom-docs-ui-assets/).

## SQL

| Параметр | Значение |
|---|---|
| Сервер | `127.0.0.1` |
| Порт | `55432` |
| База | `aml_lab` |
| Пользователь для практики | `aml_student` |
| Пользователь для чтения | `aml_reader` |
| Схемы | `practice`, `reference` |
| Пароли | Локальный файл `var/postgres/lab-connection.json`, раздел `roles` |

Консольный клиент `psql` поставляется со стендом:

```powershell
.\scripts\lab\Open-Sql.ps1
```

Попробуйте `SELECT * FROM practice.clients;`. Для выхода введите `\q`. Ключ `-ReadOnly` подключает роль чтения. В графическом SQL-клиенте используйте параметры из таблицы и пароль роли `student` из локального файла; драйвер — PostgreSQL, SSL для данного loopback-подключения выключен.

В [SQL-заданиях](sql/exercises.sql) — 12 упражнений: фильтры, JOIN, агрегаты, CTE, оконные функции, точные суммы, UTC-интервалы, транзакции и ограничения. [Решения](sql/solutions.sql) лежат отдельно. Чтобы выполнить весь файл решений:

```powershell
.\scripts\lab\Open-Sql.ps1 -File .\lab\sql\solutions.sql
```

## API и Swagger

После открытия Swagger нажмите **Authorize**. Значение для `X-Lab-Key` можно скопировать в буфер из PowerShell:

```powershell
$labAccess = Get-Content .\var\postgres\lab-connection.json -Raw | ConvertFrom-Json
$labAccess.api_token | Set-Clipboard
```

Ключ хранится только локально в исключённом из Git каталоге `var`. Swagger не сохраняет авторизацию после перезагрузки страницы. Кнопки **Try it out → Execute** отправляют настоящие запросы в вашу учебную БД.

- `GET /lab/clients`, `/cards`, `/incidents`, `/transactions`, `/rules` читают `practice`.
- `/lab/notes` позволяет создавать, читать, менять и удалять заметки `practice.case_notes`.
- Изменение и удаление требуют актуальной `expected_revision`; устаревшее значение даёт `409 VERSION_CONFLICT`.
- `GET /health` подтверждает работу HTTP; защищённый `GET /lab/status` проверяет соединение с БД.

[API-практикум и примеры](api/README.md). Фактическая схема доступна по [OpenAPI JSON](http://127.0.0.1:8765/openapi.json); её проверенная копия сохраняется в `verification/block-06/runtime-openapi.json`. Исторический `contracts/v1/openapi.json` остаётся проектным контрактом блока 2 и не является полной схемой этого сервера.

## Что меняют упражнения

`reference` хранит исходный проверенный снимок: 5 клиентов, 4 карты, 5 инцидентов, 15 транзакций, 5 правил. Учебные роли читают его. `practice` — отдельная изменяемая копия; студент может менять данные и структуру. API меняет только заметки. После собственных DDL-экспериментов структура может перестать соответствовать API.

Для явного удаления учебных изменений, заметок и созданных объектов в `practice`:

```powershell
.\.venv\Scripts\python.exe -I -B scripts\lab\database.py reset-practice --confirm-practice-reset
```

Завершите открытые SQL-транзакции и API-упражнения перед восстановлением. Эталон `reference` и результаты workflow не сбрасываются. Запуск сервера и повторный `bootstrap` ничего автоматически не обнуляют.

Группа `/v1` в Swagger подключает сохраняемый AML workflow. Он читает зафиксированные JSON-файлы `data/demo-v1`, а его задания/решения хранятся отдельно в SQLite `var/workflow/api-workflow.sqlite3`. Изменение SQL-таблиц **не меняет входные данные агента**. Подготовка моделей начинается только при явном `POST /v1/readiness`; затем для задания нужны `demo=true`, `Idempotency-Key` и окно из `config/demo-policy.json`. `engine=template` использует retrieval без генерации Ollama; `local-model` требует работающей локальной модели. Подробности — в [описании workflow](../docs/rebuild/workflow-runtime.md).

Заметки SQL не являются решениями оператора. Учебный ключ соответствует одному локальному пользователю и не заменяет банковский IAM. Правила и результаты синтетические; предметная политика ожидает согласования эксперта.

## Проверки и диагностика

```powershell
.\scripts\lab\Test-Lab.ps1
```

Эта команда проверяет HTTP-границы, SQL-права/ограничения и реальный API. Обычная проверка не сбрасывает `practice`; после ваших изменений ожидаемые исходные результаты могут отличаться. Свидетельства повторных запусков сохраняются в `var/checks/lab`, исходная приёмка — в `verification/block-06`. Тесты создают только собственные временные заметки и удаляют их. Отдельный reset-test предназначен для квалификации свежего стенда, в обычную команду не включён.

Логи: `var/logs/postgres-lab.log` и `var/logs/lab-api.err.log`. Если порт занят, скрипт завершится с ошибкой; чужие процессы автоматически не останавливаются. Неожиданное изменение метки владельца кластера требует ручной проверки. Пароли и токен не включены в отчёты проверки.
